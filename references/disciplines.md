# 按学科与论文类型阅读

共同要求是研究问题、关键贡献、证据强弱、适用条件、局限与可借鉴之处。以下为阅读检查点，不是要求每篇都必须报告的固定指标。

| 学科或研究类型 | 优先核对 | 常见误读 |
| --- | --- | --- |
| 自然科学 土壤 生态 环境 | 实验单位、独立重复、对照、时间尺度、测量方法、通量与库量；土壤研究再区分浓度、占比和储量 | 技术重复当生物重复；相关性当机制；某组分增加当总量净增加 |
| 医学与生命科学 | 人群或模型、研究设计、样本量、随机化与盲法、主要终点、效应量及置信区间、偏倚与外部适用性 | 细胞或动物结果直接当临床疗效；替代终点等同患者获益；观察性关联等同治疗效果 |
| 计算机与人工智能 | 任务定义、数据集与划分、泄漏风险、基线公平性、消融、重复运行、算力成本、复现材料、泛化范围 | 单榜单领先当普遍能力；训练数据重叠当独立验证；忽略资源条件 |
| 工程与材料 | 材料制备或系统边界、测试条件、基准、重复性、性能权衡、耐久性、规模化与成本 | 条件不同的数值直接比较；小样性能当工程可用性 |
| 经济与实证社会科学 | 数据来源、研究对象、样本选择、识别策略、内生性、稳健性、效应大小、外部有效性；质性研究看资料与解释链 | 相关回归等同因果；统计显著等同实际重要；特定群体结论随意外推 |
| 数学 理论 计算理论 | 定义、假设、定理陈述、证明结构、关键引理、边界与反例；区分严格证明、数值检验和猜想 | 省略前提推广定理；把仿真当证明；给无实验的论文编样本量 |
| 人文与解释性研究 | 问题、概念、材料版本与语境、文献定位、论证链、反证与替代解释 | 把作者解释当唯一事实；脱离语境转述；套用不适用的量化指标 |

综述需说明检索与选择方法、证据覆盖范围及争议；叙述综述不冒称系统综述或元分析。方法论文需说明相对已有方法解决的问题、验证设计与适用范围。预印本明确标识未经同行评审，若存在正式版本则核对差异与版本。

医学论文简读属于学术阅读；不将论文结果转为个体诊疗建议。法律或政策研究注明文献对应的法域和时期，不将历史材料描述为当前规定。科研前沿、撤稿和更正状态以当次核验为准。
